Values across five Asian countries

An exploratory analysis of simulated survey data · 8,495 complete responses

This analysis uses synthetic (simulated) data. Every row in data/wvs-synthetic.csv is fabricated. The dataset was generated to resemble the distributions and relationships found in the World Values Survey, Wave 7 (2017-2022), which serves only as the model it imitates - no real respondent data is used here. Every pattern below is therefore illustrative only and must not be read as evidence about any real country or population.

The five countries covered, one from each part of Asia, are Turkey (Middle East), India (South Asia), Singapore (Southeast Asia), China (East Asia) and Kazakhstan (Central Asia). Sample sizes differ by country.

Model for the simulation: Haerpfer, C., Inglehart, R., Moreno, A., Welzel, C., Kizilova, K., Diez-Medrano, J., Lagos, M., Norris, P., Ponarin, E. & Puranen, B. (eds.), World Values Survey: Round Seven - Country-Pooled Datafile. Madrid & Vienna: JD Systems Institute & WVSA Secretariat. worldvaluessurvey.org

Quality checks

Duplicates and missing values

Duplicates

Checked two ways. Identical rows across all 15 columns: 0 found. Repeated respondent_id values: 0 found. No duplicates were present, so no rows were removed on this account.

Missing values

10 of the 14 analysed variables contain blanks (income_level 197, trust_people 139, importance_of_god 97, emancipative_values 95, education 92, freedom_of_choice 80, financial_satisfaction 55, marital_status 51, life_satisfaction 45, secular_values 34). Following the brief, any row with an empty cell anywhere is dropped from the analysis: 834 rows removed (9% of the file), leaving 8,495 complete rows (91%) for every figure below.

Because blanks are not spread evenly, this listwise deletion hits the countries unequally - Kazakhstan loses the largest share - which is worth keeping in mind when comparing them.

Cultural map: emancipative vs secular values

Each point is one country's average, in the style of the Inglehart-Welzel cultural map. Right means more secular, up means more emancipative.

Analysis 2

Value fingerprints across six measures

Six measures, each rescaled to run 0-1 so they share one axis: the three 1-10 satisfaction and religiosity items are divided by 10, trust_people is the share answering “Trusted”, and the two value indices are already on a 0-1 scale. Each country has its own colour, marker and line style.

Individual respondents: China vs India

The same two axes as the cultural map, but one point per person - a random sample of 300 respondents from each country (seeded, so this figure is reproducible) drawn from 2,882 Chinese and 1,567 Indian complete responses. The large outlined markers are each country's average across all of its respondents, not just the sample.
